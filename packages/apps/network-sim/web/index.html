🌐 Qu est-ce qu un réseau ?

Un réseau informatique est un ensemble d équipements reliés entre eux pour échanger des informations. Les données circulent sous forme de paquets qui suivent des chemins définis par des protocoles.

  • LAN (Local Area Network) : Réseau local
  • WAN (Wide Area Network) : Réseau étendu comme Internet
  • IP : Adresse unique identifiant chaque équipement
  • MAC : Adresse physique de la carte réseau

📡 Les équipements réseau

Chaque équipement a un rôle spécifique :

  • Routeur : Dirige le trafic entre différents réseaux
  • Switch : Connecte les équipements d un même réseau
  • Firewall : Filtre le trafic selon des règles de sécurité
  • Serveur DNS : Traduit les noms de domaine en adresses IP

💥 Attaque DDoS

Une attaque DDoS vise à rendre un service indisponible en le submergeant de requêtes. Des milliers de machines compromises envoient simultanément du trafic vers la cible.

Protection : Rate limiting, pare-feu applicatif, services anti-DDoS.

🕵 Attaque Man-in-the-Middle

L attaquant s interpose entre deux parties, interceptant et modifiant potentiellement les données échangées.

Protection : Chiffrement TLS/SSL, HTTPS, VPN.

🎭 DNS Spoofing

L attaquant falsifie les réponses DNS pour rediriger vers un faux site web.

Protection : DNSSEC, DNS over HTTPS.

📍 ARP Poisoning

L attaquant envoie de fausses réponses ARP pour associer son adresse MAC à l IP de la passerelle.

Protection : ARP statique, segmentation réseau, 802.1X.

🔐 Le chiffrement TLS

TLS chiffre les communications entre client et serveur.

  • Authentification du serveur via certificat
  • Chiffrement des données en transit
  • Intégrité des données

🛡 Les couches de défense

La sécurité en profondeur combine plusieurs mesures :

  • Firewall : Première ligne de défense
  • IDS/IPS : Détecte les comportements suspects
  • Chiffrement : Protège la confidentialité
  • 2FA : Renforce l authentification
  • VPN : Crée un tunnel sécurisé
